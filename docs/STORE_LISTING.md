# Chrome Web Store copy and screenshot plan — v1.6

## Short description

Control any HTML5 video from 0.1×–16× with custom presets, shortcut chords, silence skipping,
per-site memory, filters, loops, and a lightweight active-player overlay.

## Description opener

Video Speed Controller Pro is built for courses, lectures, tutorials, reviews, and long-form
video. It follows the player you are actually using—even on pages with feeds and embedded
frames—without moving the video or interfering with the site's layout.

Core controls are one click away in the compact popup: play/pause, current speed, custom presets,
fine step controls, and remaining wall-clock time at the selected speed. Advanced settings cover
shortcut chords, site and URL rules, appearance, A–B loops, intro/outro skips, filters, volume
boost, and opt-in silence skipping.

Everything runs locally. There is no analytics SDK or developer backend. Settings can use Chrome
Sync; the time-saved counter stays in local extension storage.

## Feature bullets

- 0.1×–16× playback with a configurable global step and up to 12 presets
- Exact Control/Alt/Shift/Meta shortcut chords with conflict protection
- One active-player controller across dynamic feeds, open shadow roots, and embedded frames
- Play/pause and speed-adjusted remaining time in the popup and overlay
- Per-site memory plus first-match URL speed rules
- Optional silence skipping with threshold, minimum duration, and skip speed
- A–B loops, frame stepping, screenshots, video filters, and up to 600% volume boost
- Spanish, Brazilian Portuguese, French, German, and Japanese UI catalogues
